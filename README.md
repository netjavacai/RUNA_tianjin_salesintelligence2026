# 天津区域经营战报 HTML 说明

本目录为手机端静态 HTML 复盘页面，适合本地打开，也可作为发布前预览版本。

## 建议阅读顺序

1. `index.html`：第一视角经营复盘首页，先看经营判断和下一步动作。
2. `pages/customers.html`：客户详细页。
3. `pages/competitors.html`：竞品详细页。
4. `pages/platform.html`：天津区域客户推进与复盘台账。
5. `pages/appendix.html`：附件索引，主要用于内部追溯。

## 文件说明

- 样式和交互文件：均为本地引用，无外部资源。
- 后续补充核实事项：内部补证清单。
- 旧版原始追溯清单：建议内部保留，不建议对外使用原名称。

## 使用边界

本轮未生成新的 Word，未修改原始业务资料，未刷新任何业务数据。页面中的客户、竞品和案例判断仍需以后续拜访和授权材料继续完善。
