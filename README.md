# RUNA 天津大区销售智能平台 · 513 比武大会

> **2026 年 5 月 13 日** · 天津赛区销售精英竞技排行榜

## 项目简介

本项目为 **513 比武大会**（RUNA 天津大区 2026 年 5 月 13 日销售竞技赛事）的实时排行榜与赛事信息展示系统。

## 功能特性

- ⚔️ **个人排行榜** — 基于积分的实时选手排名，含达标率进度条与状态标签
- 🏆 **团队排行榜** — 4 支战队的团队销售总额与综合积分对比
- 📋 **赛制说明** — 参赛资格、积分规则、奖励方案及赛程安排
- ⏱️ **倒计时** — 距赛事开始的实时倒计时
- 📊 **统计摘要** — 参赛人数、累计销售额、平均达标率等关键指标
- 🔄 **自动刷新** — 每 5 分钟自动同步最新数据

## 积分规则

| 条件 | 得分 |
|------|------|
| 完成月度目标 100 % | 基础分 100 分 |
| 每超额 10 % | +15 分 |
| 每新增签约客户 | +20 分 |
| 客户满意度 ≥ 4.5 星 | +10 分 |

## 奖励方案

| 名次 | 奖励 |
|------|------|
| 个人冠军 | ¥10,000 + 荣誉证书 |
| 个人亚军 | ¥6,000 + 荣誉证书 |
| 个人季军 | ¥3,000 + 荣誉证书 |
| 团队冠军 | 每人 ¥5,000 + 团队奖杯 |
| 前 10 名 | 出行激励名额 |


## 快速使用

直接在浏览器中打开 `index.html` 即可查看排行榜。生产环境中，`data.js` 中的数据应替换为从 CRM 系统获取的实时接口数据。
